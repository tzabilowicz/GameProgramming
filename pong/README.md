# Pong
Source code for the game of pong in C++. The game is dervied from *Game Programming in C++* by Sanjay Madhav with some modifications.

## Playing the Game
The source code (.h/.cpp) files are provided. Either create a Visual Studio project adding the SDL dependency, or manually compile the program combined with the SDL source code.

You can switch between 1- and 2-player game modes in the code. The 1-player game mode uses a computer based second player (it only responds to 1 ball on the screen and is practially unbeatable). Additionally the game supports multi-ball pong. By pressing the space button, it adds new balls to the game in a burst.
